## 1. 结论速览

- **P0：0 项**（未发现可导致未授权数据泄露、鉴权绕过或越权写入的可利用缺陷）。
- **P1：7 项**，集中在「令牌生命周期/角色时效」「对象级越权错误语义」「内部接口文档暴露」「审计覆盖」「登录限流可绕过」。
- **P2：4 项**（本地固定 JWT 密钥、CSP/HSTS 未下发、audit_record 无来源 IP、内部令牌本地未注入的可用性影响）。
- 正向结论：
  1. JWT 校验链完整（签名+有效期+用户状态回查），PUBLIC/AUTH/ROLE 三层规则与 `@PreAuthorize` 双层防线齐全；
  2. 练习/模拟考等按记录 ID 访问的接口**均有属主校验**，不存在直接越权读写的路径；
  3. `X-Internal-Token` fail-closed（未配置/缺失/不匹配一律 403，常量时间比较）；
  4. 管理端审核、题目删除、用户改状态/角色**已落** `audit_record` / `operation_log`（含 ip、UA）。

## 4. 整改建议（不实施，仅建议）

1. **令牌生命周期（P1-1/P1-2）**
   - 增加 `POST /auth/refresh`（短 access token + 长 refresh token，或改为 2h access + 每日续期）；
   - 引入 `token_version`（user 表）或 Redis 黑名单：logout / 改角色 / 禁用时递增，过滤器比对 claim 的 `ver`；
   - 角色在库内变更后 bump `token_version`，使旧令牌立即失效（无需等 7 天）。
2. **错误语义（P1-3 / A-07）**
   - `GlobalExceptionHandler.setStatusIfHttpRange` 之外增加业务码映射（1001→401、2001/2003→404、4001→403），至少让 `LOGIN_FAILED`、`PRACTICE_NOT_FOUND` 同步 HTTP 4xx；
   - 对象级越权建议统一 `403`（或保持 404 以隐藏存在性，但必须同步 HTTP 状态）。
3. **内部接口文档（P1-4）**
   - 在 `OpenApiConfig` 用 `GroupedOpenApi`/`pathsToExclude("/internal/**")` 排除，或给两个 Internal Controller 加 `@Hidden`；保留 `/v3/api-docs` 匿名可读的便利。
4. **审计（P1-5/P1-6）**
   - `AuthService.login` 成功/失败、`logout` 调 `OperationLogService.record/recordAs`（失败登录记 username+ip，避免记密码）；
   - `/admin/ai/retention/purge`、公告删除补 `operation_log`（module=ADMIN/AI，记录 deleted 行数与 cutoff）。
5. **限流（P1-7）**
   - 仅在可信代理（回环/内网 nginx）存在时采用 XFF，否则用 `request.getRemoteAddr()`；或与 nginx `real_ip` 配置联动。
6. **可选**：给 `audit_record` 增 ip/ua 列，或统一以 `operation_log` 作为唯一审计源。

$base = "http://127.0.0.1:8080/api"
function Call($method, $url, $body, $headers) {
  $p = @{ Method=$method; Uri=$url; UseBasicParsing=$true; TimeoutSec=15 }
  if ($body) { $p.Body = ($body | ConvertTo-Json -Compress); $p.ContentType = "application/json" }
  if ($headers) { $p.Headers = $headers }
  try {
    $r = Invoke-WebRequest @p
    [pscustomobject]@{ status=[int]$r.StatusCode; body=[Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray()) }
  } catch {
    $resp = $_.Exception.Response
    if ($resp) {
      $sr = New-Object IO.StreamReader($resp.GetResponseStream())
      [pscustomobject]@{ status=[int]$resp.StatusCode; body=$sr.ReadToEnd() }
    } else { [pscustomobject]@{ status=-1; body=$_.Exception.Message } }
  }
}
