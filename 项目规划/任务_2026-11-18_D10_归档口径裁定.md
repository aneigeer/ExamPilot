### 2.3 判据裁定

> **判据：10 份周计划 docx「周末状态记录」是否回填，唯一有效判据 = `word/document.xml` 正文可见文本中的 Unicode `☑`（勾选字符）与「实际完成日期：」后的文本。`<w:checkBox>` / `<w:checked>` / `<w:ffData>` 等 XML 表单域元素数不作为判据。**

理由：

1. **载体事实**：10 份 docx 中表单域元素**恒为 0**（上表），说明该批文档从生成起就不是 Word 表单域文档，勾选框是正文 `<w:t>` 里的 `□`/`☑` 纯文本字符。拿 XML 控件当判据，测的是「有没有控件」，不是「有没有回填」。
2. **错误结论可证伪**：若以 `<w:checkBox>` 数为判据，会得出「**0/10 回填**」；而实测可见文本为「**9/10 回填**」。前 9 份已有勾选字符与日期，与 `项目规划/收尾_2026-11-11_已知限制与未修项.md:105-107`「成功 9/9（W10 跳过）」逐份吻合。故 XML 判据与事实不符，必须弃用。
3. **两套旧结论是判据冲突，不是事实冲突**：`项目规划/审计_2026-11-10_汇总结论.md:46` / `:80`(#6) 的「0/10」按 XML 控件判据得出；`限制:105-107` 的「9/9」按可见文本判据得出。本文采信后者，并在 `T2:266`（§5.2）已登记「需由 D10 明确判据」之上给出裁定。
4. **不改写历史**：本文不修改上述任何旧文件的原文；`审计:46` 的「0/10」在其自身判据下仍可复现，只是**不能用来否定可见文本已回填**。
