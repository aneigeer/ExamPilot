## 2. 关键结果

### 2.1 数据流（W8-1）
- 三条流：刷题、AI 答疑、知识库导入；入口 Android → Spring Boot `:8080/api`，FastAPI `:8000` 仅内部；管理端静态页 + JWT。
- 实测状态：8080/8000/3306/11434 UP，6379 DOWN；Nginx 80/443 未监听。
- 已暴露契约风险：internal 端点出现在 Swagger、`FastApiClient` 不带 `X-Internal-Token`、Python `/v1/ask` 是第二套 RAG（Java 不调用）、发布后向量不同步。

### 2.2 刷题 E2E（W8-2）
- **36 条接口用例：33 通过 / 3 失败**；**数据库核对 8/8**。
- 主链路通过：登录 → 取题（total=2500）→ 开始练习（practice 21/22）→ 判分（1 对 1 错）→ 重复提交幂等 → finish 报告 50% → 错题本命中 → 收藏复原 → 统计 +1/+2/+1 → 库表一致。
- 失败：错误密码返回 HTTP 200/业务码 1001；不存在 practiceId 返回 HTTP 200/2003；答案无长度限制（20,000 字符入库）。

### 2.3 AI 答疑 + Agent/面试（W8-3）
- **29 条用例：24 通过 / 5 失败**；DB 9 项：6 通过 / 3 未达预期。
- 通过：域内答疑 200 + 引用 + sources；Wiki 热层 29ms 命中；域外天气正确拒答；无 token 401；参数边界 400；Python Agent 工具成功/非法参数/未知工具拦截/失败不崩溃；SSE 事件序列可解析。
- 失败：`app.ai.agent.enabled=false` → Java Agent SSE 503（runs 却 200）；面试 503；域外「红烧肉做法」未拒答；非法 subjectId 200；无 `ai_qa_record` 表（答疑不落库）；Wiki `refPath` 无对应路由。

> **主 agent 修正**：面试 503 的根因**不是 Qdrant 6333 未启动**（AI 服务实际用本地 file 模式 `./data/qdrant`），而是**面试语料未入库/未索引**（`interview.py` 走同一个 `get_qdrant_client()`，报「向量检索无命中」）。6333 未监听是正常状态，不作为缺陷。

### 2.4 知识库导入闭环（W8-4）
- 上传 → 审核发布 → 切分 → `ai_chunk` 新增 **1 条（id=19066）** → 人工调用 `/admin/ai/vector/sync` → 学生端 `/ai/ask` 命中（`refId=8`、`VECTOR_HYBRID`）；内部检索与 MySQL ngram 均命中；对账 **12648=12648**。
- 缺陷：发布只置 `vector_synced=0` 不自动推向量（中危）；无课件导入写接口（中危）；docx/txt 正文不进索引（中危）。

### 2.5 故障注入（W8-5）
- S1 停 Ollama：`/ai/ask` 仍 200、`generator=extractive`、`degraded=true`、sources=2，2.5s；恢复后 `generator=ollama`、`degraded=false`。
- S2 停 8000：`/ai/ask` 200、`FULLTEXT_OR` 降级、1.7s；Java 健康 200；Python 直连按预期不可用。
- S3 Redis DOWN：jobs 503 快速失败（16ms，实际来自 `app.ai.jobs.enabled=false` 闸门）。
- S4 数据库断连、S5 网络/慢响应：**未注入**（保护数据与不修改防火墙），有静态/单测旁证，未标通过。
- **恢复 6/6 通过**；MySQL PID 7508 全程未变。

### 2.6 客户端兼容性（W8-6）
- 实测 3（401 鉴权、重复提交串行+并发幂等 practiceId=24、契约探测）；代码核对 4（切后台、弱网、重试、页面恢复）；受阻 1（关键机型：adb 无设备、AVD 缺镜像）。
- **D1 严重**：release 包写死 `https://10.200.83.194/api/`（`student-app/app/build.gradle:54`），该主机不可达、本机实际 IP 10.200.14.149、随包证书 SAN 不含新 IP → 真机包不可用。
- D2/D3 中级：401 后台跳转无兜底；练习页重建后主观题自评入口丢失。

### 2.7 自动化回归（W8-7）
- `scripts/qa/week8_e2e.py` 覆盖 19 条核心链路；主 agent独立复跑 **19/19 通过，退出码 0**，证据 `evidence/automation_regression_verify_20261108.json`。
- 4 条已知缺陷用 XFAIL 隔离：错误密码 200、非法 practiceId 200、「红烧肉做法」未拒答、Agent 顶层无 final。
