# D-09 修复记录：AI 服务模型名对齐

> 时间：2026-11-07
> 缺陷：`ai-service/.env` 配置 `LLM_MODEL=qwen2.5-7b`，Ollama 中不存在该模型
> 处置：改为 `qwen2.5-7b-instruct-baseline`，并验证实际推理

---

## 1. 修改内容

| 项 | 修改前 | 修改后 |
|---|---|---|
| `ai-service/.env` 第 7 行 | `LLM_MODEL=qwen2.5-7b` | `LLM_MODEL=qwen2.5-7b-instruct-baseline` |

未改动 API Key、数据库口令等其他配置。

## 2. 验证

### 2.1 Ollama 模型清单

```
qwen2.5-7b-instruct-baseline:latest    89684282222b    4.7 GB
```

`ollama show qwen2.5-7b-instruct-baseline`：

```
architecture        qwen2
parameters          7.6B
context length      32768
quantization        Q4_K_M
capabilities        tools / completion
```

### 2.2 实际推理

请求：

```json
{"model":"qwen2.5-7b-instruct-baseline","messages":[{"role":"user","content":"只回复两个字：正常"}],"stream":false,"options":{"temperature":0,"num_predict":8,"num_ctx":2048}}
```

响应：

```json
{"model":"qwen2.5-7b-instruct-baseline",
 "message":{"role":"assistant","content":"正常"},
 "done":true,"done_reason":"stop",
 "total_duration":15.79s,"load_duration":7.61s,
 "prompt_eval_count":35,"eval_count":2}
```

**结论：模型名可用，实际推理成功。**

### 2.3 一个并发注意点

首次请求时 3B 模型正被复跑占用 GPU，Ollama 返回 HTTP 500；等 3B 卸载后重试成功。
说明：**并发切换 7B/3B 会触发重载与显存竞争**，后续服务启动时应确保同一时刻只保留一个主模型，或在 Ollama 层设置队列/`keep_alive`。
