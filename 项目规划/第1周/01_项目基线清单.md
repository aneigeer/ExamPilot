## 5. 运行时基线

| 服务 | 端口 | 探活结果 |
|---|---|---|
| Spring Boot 后端 | 8080 | **未运行**（连接失败，HTTP 000） |
| FastAPI AI 服务 | 8000 | **未运行**（连接失败，HTTP 000） |
| Ollama | 11434 | 运行中，返回 2 个模型 |

### P0 缺陷：生产配置指向不存在的模型

`ai-service/.env`（2026-10-27 最后修改）关键项：

```
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_MODEL=qwen2.5-7b
LLM_GENERATOR_NAME=ollama
```

但 Ollama 实际只有 `exam-prep-7b` 与 `qwen2.5-7b-instruct-baseline`。实测调用：

```bash
curl -X POST http://127.0.0.1:11434/api/chat -d '{"model":"qwen2.5-7b",...}'
# {"error":"model 'qwen2.5-7b' not found"}
```

**影响**：AI 服务一旦启动，所有走默认 LLM 的答疑请求都会失败（模型不存在），且会被降级链吞掉，表现为「答非所问」或「服务不可用」。
**处置建议**：本周内改为实际存在的模型名（`qwen2.5-7b-instruct-baseline` 或 `exam-prep-7b`，后者需先评测），或显式切到在线 API，并在 `.env.example` 里写清合法取值。
