## 2. 复筛方法（为什么不是只看前 3 页）

原 `note` 的判据是「pypdf **前 3 页**文本为空/极少 → 扫描件」。§11.1 已证明：任何带封面 / 目录 / 插图前言的原生 PDF，前几页都可能是图；5072 第 1 页 0 字符、第 2 页就有 1846 字符。本轮对每本 PDF 做**全页**文本层判定，而不是只看前几页。

### 2.1 为什么不用逐页 `extract_text`

实测纯扫描图页（id=4631，159.6 MB / 56 页）单页 `extract_text` 约 **5.6 s**（10 页 44.9 s、前 25 页 140.5 s）。若对 391 条逐页抽取，会被拖到小时级，且子进程超时会把大册子误记为「无法读取」——反而漏掉最可能可救回的原生 PDF（首版全页逐页方案实测 22 分钟仅完成 150/391，已废弃）。故改用**结构判据 + 有限抽测**：

| 步骤 | 做法 | 成本 |
|---|---|---|
| ① 全页结构扫描 | 逐页检查 `/Resources /Font`（含 `/Parent` 继承）。PDF 文本必须由字体绘制，**无 /Font 即无文本层**；不解码内容流 | 实测 0.01–0.13 s/本（200 MB / 259 页仅 0.08 s） |
| ② 字符数抽测 | 仅对「有 /Font」的页调 `extract_text`，每本最多 8 页，统计字符数与乱码率 | 原生 PDF 每页约 0.01 s |
| ③ 采样点 | 采样点=第1/2/3页+随机1页(seed=20261114+id)+1/4、1/2、3/4 分位页+末页；另补有字体页的首/中/末；每本最多 8 页调 extract_text | — |

**判据交叉验证**（复筛前独立探测，属方法验证，非 391 条结论）：

| 样本 | 页数 | 前 3 页 `extract_text` | 中段页 `extract_text` | 全页有 /Font |
|---|---:|---|---|---:|
| id=5123 六级仔细阅读专项真题（200.5 MB） | 259 | 0 / 0 / 0 字 | 第 32 页 2387、第 130 页 2590 字 | **256** 页 |

| id=858 / 4625 / 8769（扫描件对照） | 20 / 56 / 40 | 0 字 | 抽样全 0 字 | **0** 页 |

→ /Font 判据与 `extract_text` 结果一致，且能定位「前 3 页是封面、中段才有正文」的误判。

### 2.2 判定阈值

| 项 | 口径 |
|---|---|
| 实质文本页 | 单页 `>= 100` 字符 **且** 乱码率 `<= 2%`（沿用 `scripts/ocr_answer_books.py` 的私有字体编码判据） |
| 可救回判据 | 抽测中实质文本页 `>= 2`（对应判据「≥2 个非空页的字符数证据」） |
| 真扫描件判据 | 全页 0 页有 /Font（无文本层）；或有字体但抽测未达 ≥2 个实质文本页（含私有字体乱码） |
| 无法读取 | 文件不存在 / 加密 / 页数为 0 / pypdf 抛异常 / 子进程崩溃或超时 |
| 可解析字符数 | `estimated_parseable_chars` = 抽测有效页平均字符数 × 全页有字体页数（**估计**）；`measured_valid_chars` = 抽测页实测有效字符总和（**下界**） |

补充：四六级答案册历史上存在「文本层是私有字体编码、pypdf 抽出乱码」的册子（`scripts/ocr_answer_books.py`），仅看字符数会把它误算成可救回，故加入乱码率判据。这类仍归 `SCAN`（需 OCR），并在逐条 `reason` 中注明。

## 5. 重解析耗时与可节省机时

| 项 | 数值 | 依据 |
|---|---:|---|
| 误排 OCR 基准 | 16.5 s/页 | 收尾执行记录 §7 / T9 §511 实测 |

算式：

```
误排 OCR 机时   = 685 页 × 16.5 s/页 = 11302.5 s = 3.14 h
重解析预计机时   = 656 有字体页 × 0.0508 s/页 = 33.3 s = 0.56 min
可节省机时       = 11302.5 − 33.3 = 11269.2 s = 3.13 h
```

**口径限定**：重解析机时只含 `pypdf` 对有字体页的文本抽取（本次实测速率），**不含**后续切块、写 `ai_chunk`、向量化与人工校对；历史同量级动作参考收尾记录 §9.1（303 册 21738 块 54.9 s、向量化 400.8 s）与 §11.1（5072 切 485 块、向量化 4.1 s）。因此实际「重解析到可检索」的墙钟时间会高于上表，但相对 16.5 s/页 的 OCR 仍是数量级差异。该数值为**估算**，非实测重解析全流程。
