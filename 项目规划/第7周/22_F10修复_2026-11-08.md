## 1. 复现症状

用例 C「函数专题的 Wiki 页面讲了什么」经 `/v1/agent/run` 返回：

- `generator=ollama`、`degraded=false`、`refused=false`
- 但 `answer="未找到相关资料[1][2][3]。"`

即「未找到资料」同时带 3 条可溯源引用，语义自相矛盾。同时 `search_wiki` 在请求无 `subjectId` 时命中 10 页全跨学科页面（pageId 12/17/38）。

## 2. 根因（三层叠加）

| # | 位置 | 问题 |
|---|---|---|
| 1 | `backend/src/main/java/com/examprep/controller/AgentInternalController.java:251`（修复前） | `refused` 判据只有 `answer.sources() == null \|\| isEmpty()`。草稿「未找到相关资料[1][2][3]。」经 `LlmClient.resolveSources`（`LlmClient.java:103`）解析出 3 条 sources → sources 非空 → `refused=false` |
| 2 | `backend/src/main/java/com/examprep/service/ai/AiQaService.java:217-241` | `ask()` 已有不变量「`refused=true` ⇒ 正文归一为 `REFUSAL_TEXT`、sources 不对外」，但 Agent 定稿路径（`answerWithContexts` 与 Controller 组装）没有复用 |
| 3 | `backend/src/main/java/com/examprep/controller/WikiInternalController.java:74-76`（修复前） | 直接返回 `wikiQueryService.search(...)` 全部命中，未应用 `hitThreshold()`；而 `WikiQueryService.search` 的 javadoc（`WikiQueryService.java:85`）明确写「不应用命中阈值，Agent 工具与观测用」→ 低分跨学科向量命中直接进 contexts |

要点：`AnswerPostProcessor.isRefusal`（`AnswerPostProcessor.java:128-137`）本就覆盖「正文含 `REFUSAL_TEXT` / sources 空 / generator=none」三条件，问题不在判据，而在**输出组装没守住不变量**。

---

## 3. 改法（最小改动）

### 3.1 `AgentInternalController.answer`

- 在「有 contexts」的两个子分支汇合后集中计算一次 `refused = answerPostProcessor.isRefusal(answer)`；
- `refused=true` 时：正文归一为 `PromptBuilder.REFUSAL_TEXT`，`sources` 返回 `List.of()`，并打一条 warn（含 generator / sources 数 / 原正文长度，措辞对齐 `AiQaService.ask:226-234`）；
- `refused=false` 时：正文与 sources 原样返回，`degraded` 公式不变；
- 空 contexts 分支（走 `aiQaService.ask`）**未改动**：其 `AskVO` 已满足不变量，字段照旧返回；
- 顺带把该文件内 `com.examprep.service.ai.PromptBuilder.isLlmGenerator` 的全限定引用改为已导入的短名（无行为变化）。

### 3.2 `WikiInternalController.search`

- 读取 `wikiQueryService.hitThreshold()`，逐条丢弃 `hit.score() < threshold` 的命中；
- 过滤后为空则照常返回空 `hits`，不抛异常；
- 只影响 Agent 工具接口，`WikiQueryService.query/search` 的公共语义未动（热层问答仍由 `query()` 自行判阈值）。

### 3.3 新增测试

`backend/src/test/java/com/examprep/controller/AgentInternalControllerAnswerTest.java`（4 条用例）：

| 用例 | 断言 |
|---|---|

| `traceableDraftIsKept` | 草稿「值传递是复制一份，地址传递是传地址 [1]。」+ 可溯源 contexts → `refused=false`、正文原样、`sources` 保留 1 条 |

| `wikiSearchReturnsEmptyWhenAllBelowThreshold` | 全部低于阈值 → 空列表，不抛异常 |

实现方式：`new AnswerPostProcessor(mock(ExtractiveAnswerClient.class))` + Mockito mock 其余 10 个构造依赖，与现有 `AiQaRefusalInvariantTest` 风格一致。**未修改任何已有测试断言。**
