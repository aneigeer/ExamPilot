# 功能大纲（现状全量 · 2026-10）

> 本文档描述**当前代码里已经实现**的功能边界，作为「有什么」的清单；
> 与 [`大纲-v2.md`](大纲-v2.md)（需求蓝图 =「要什么」）互补。

## 1 系统总览

| 端 | 技术栈 | 规模（实测） |
|---|---|---|
| 学生端 | Android 原生：Java + XML + ViewBinding + Retrofit/OkHttp/Gson + Glide + Material 3（minSdk 26 / targetSdk 34） | 28 个页面（24 个 Activity 页面 + 4 个 Fragment） |
| 管理端 | Vue3 + Element Plus（CDN 本地化单页应用） | 由后端同源托管（`/api/admin/index.html`），零构建、零跨域 |
| 后端 | JDK 21 + Spring Boot 3.5.3 + Spring Security 6 + JWT + MyBatis-Plus 3.5.7 + springdoc-openapi | 151 个接口 / 25 个 Controller |
| 数据库 | MySQL 8.0（utf8mb4） | 43 张表；schema + data + 9 个增量迁移（均可重复执行） |
| AI 导学 | Spring Boot 内 RAG + 可选 Python 微服务（FastAPI + Qdrant + 大模型） | 五层降级；Recall@5 = 91.7%，拒答准确率 = 100% |

## 2 学生端功能（Android）

### 2.1 账号与准入

| 功能 | 说明 |
|---|---|
| 首次启动隐私弹窗 | 未同意不得进入（`LoginActivity` 拦截） |
| 游客模式 | 免登录浏览考试体系/题库/资料前 3 页/搜索；受限：下载、上传、刷题、评论、收藏 |
| 自助注册 | 学号全局唯一（重复 409）；须选学校，学院/年级可选；成功后自动登录 |
| 登录 | 学号 + 密码（BCrypt）；JWT 有效期 7 天；失败统一提示，不暴露学号是否存在 |
| 修改密码 | 需原密码；新密码 ≥8 位且含字母与数字 |
| **导出个人数据** | 「账号设置」→ 拉取本人数据 JSON 落盘 → 系统「保存/分享」 |
| **注销账号** | 「账号设置」→ 二次确认弹窗 + 输入密码；注销即匿名化且不可恢复；旧令牌立即失效 |

### 2.2 首页

平台统计、公告、考试类别入口、热门资料、顶部搜索条；右下角悬浮按钮 = 上传资料。

### 2.3 题库与刷题

| 环节 | 功能 |
|---|---|
| 浏览 | 考试类别 → 科目 → 知识点树 → 题目列表/按科目或知识点刷题 |
| 刷题配置 | 科目 / 题型 / **模式**（顺序·随机·错题重做）/ **范围**（混合·只客观·只主观）/ **难度**（不限或 1–5）/ **题数**（1–100） |
| 作答 | 客观题点选即时判分（对错 + 正确答案 + 解析）；填空用 `|` 分隔多空；匹配题按 `A:1,B:3`；排序题按 `C,A,B`；组合大题「材料 + 子题」整体提交；主观题自评「会了/模糊/不会」 |
| 辅助 | 顶部「答题卡」查看进度与跳题；「交卷」出报告（正确率 + 逐题明细） |
| 报告 | 练习报告含逐题对错、你的答案与正确答案 |

**题型枚举**（`question.type`，全量 22 种，界面按批次开放）：
`SINGLE_CHOICE` / `MULTI_CHOICE` / `TRUE_FALSE` / `FILL_BLANK` / `MATCHING` / `ORDERING` / `CLOZE` /
`READING` / `LISTENING` / `WORD_FILL` / `SHORT_ANSWER` / `ESSAY` / `TERM_EXPLAIN` / `CALCULATION` /
`APPLICATION` / `PROGRAMMING` / `CASE_ANALYSIS` / `WRITING` / `TRANSLATION` / `ERROR_CORRECTION` / `PROOF` / `COMPOSITE`

**判分口径**：`SINGLE_CHOICE`/`TRUE_FALSE`/`MULTI_CHOICE`/`FILL_BLANK`/`MATCHING`/`ORDERING` 由后端自动判分；
其余为主观题，走「自评」闭环。

### 2.4 错题本与间隔重复复习（SRS）

| 功能 | 说明 |
|---|---|
| 自动归集 | 作答错误自动进入错题本；重复答错累加 `wrong_count` |
| 列表 | 展示题干/题型/错误次数；点击查看详情；长按移出 |
| **间隔重复复习** | 错题本顶部「复习」→ 只练**到期**错题，节奏 1/2/4/7/15/30/60 天 |
| 复习交互 | 回忆 → 「对答案」（揭晓正确选项 + 解析）→ 自评「答对了 / 答错了」→ 服务端推进或重置阶段 → 下一题 |
| 掌握判定 | 走完全部 7 轮即标记「已掌握」，不再进入复习队列；结束汇总「本次新掌握 N 题」 |

### 2.5 模拟考试

选科目/题数/时长 → 限时作答（顶部倒计时 + 答题卡跳题）→ 交卷或**超时自动交卷** → 成绩报告。

### 2.6 资料库

列表（类型/标签/关键词筛选，分页）→ 详情：**在线预览**（游客前 3 页低清带水印、登录整本高清）、
**下载**（短时效签名链接）、收藏、评论/点赞、评分、举报；上传（App 仅图片，自动压缩，多选）。

### 2.7 课程库与关注

学院 + 学期筛选课程；关注课程/科目。

### 2.8 我的（个人中心）

学习统计（练习次数/正确率/错题/收藏/下载/上传/未读通知）、知识点掌握度、刷题趋势；
入口：错题本、我的笔记、收藏题、上传记录、我的关注、我的申诉、账号设置、我的收藏、下载历史、通知中心、退出登录。

### 2.9 上传 / 举报 / 申诉

- 上传：App 侧仅图片（jpg/jpeg/png/webp/gif），提交后进入**待审核**；上传记录可查审核状态
- 举报：资料详情页举报 → 填理由
- 申诉：被下架资料可申诉 → 「我的申诉」查看结果

### 2.10 搜索

关键词搜索资料；游客可用。

### 2.11 无障碍（视障/大字模式可用）

| 项 | 落地做法 |
|---|---|
| 图标语义 | 所有图标控件均有 `contentDescription`（移入字符串资源，可本地化） |
| 字体缩放 | 文字统一使用 `sp`，随系统字号缩放 |
| 触摸目标 | 顶部栏「当作按钮用」的文字控件统一走 `TopAction` 样式，最小 48dp |
| 对比度 | 次要文字由 `#7A8190`（实测 3.62:1）改为 `#5C6472`（浅底 5.52:1 / 白底 5.96:1），达 WCAG AA；并修正时间戳误用分隔线色作文字色（原 1.20:1，近乎不可见）的问题 |
| 状态冗余 | 对错以「文字 + ✓/✗」表达，不单靠颜色；判分结果主动 `announceForAccessibility` 播报 |

## 3 管理端功能（Web）

单页应用，后端同源托管。菜单：

| 菜单 | 功能 |
|---|---|
| 仪表盘 | 用户/题目/资料/待审核/举报/下载量统计 + 热门科目、活跃用户、题型正确率 TOP10 |
| 题目审核 | 按题型/关键词筛选 → 通过 / 驳回（填原因）/ 下架 |
| 资料审核 | 待审核 / 已审核切换 → 通过 / 驳回 / 下架 |
| 举报处理 | 成立并下架 / 不成立 |
| 申诉处理 | 通过恢复（资料重新公开）/ 驳回维持下架 |
| 用户管理 | 角色调整、禁用/启用 |
| 题目管理 | 新建题目（表单）、**批量导入/导出 JSON**、删除 |
| 文件上传 | **文档类资料（PDF/DOCX/ZIP 等）唯一上传入口** |
| 公告管理 | 发布 / 编辑 / 删除 |
| 基础数据 | 考试类别、科目、知识点、学院、教师维护 |
| 操作日志 | 全部记录（超管）/ 审核日志（审核员） |

> 规则：审核员**不能**审核自己上传的内容（系统自动拦截）；学生上传的资料/题目默认 `PENDING`，仅通过审核后进入公共题库与 AI 知识库。

## 5 AI 导学（RAG 五层降级）

**核心主张：除 MySQL 外所有组件都可摘除，任一挂掉问答与上传仍可用。**

| 层 | 通道 | 不可用时去向 |
|---|---|---|
| 0 | 学情画像（本地 MySQL） | — |
| 1 | 向量检索（FastAPI + Qdrant） | 熔断 +1 → 层 2 |
| 2 | ngram 全文检索（MySQL 内置） | → 层 3 |
| 3 | 拒答闸门（低于阈值直接拒答，反幻觉第一道） | → 层 4 |
| 4 | 大模型生成 / **抽取式兜底** | 抽取式永远可用 |

配套：答案强制溯源（带出处）、三层反幻觉、向量阈值随语料规模标定、OCR（PaddleOCR 跨版本自适应）。

## 7 合规与安全

| 项 | 落地情况 |
|---|---|
| 个人信息可携带（导出） | `GET /api/me/export` + 学生端入口 ✅ |
| 删除权（注销） | `POST /api/me/deactivate`（校验密码 + 确认语 → 匿名化 + 逻辑删除）+ 学生端入口 ✅ |
| 令牌失效 | JWT 过滤回查用户；注销/禁用后旧令牌立即失效 ✅ |
| 明文流量收口 | release 默认禁明文；debug 变体覆盖允许明文以联调 ✅ |
| 安全响应头 | `X-Frame-Options=DENY`、`nosniff`、`Referrer-Policy`、`Permissions-Policy` ✅ |
| CSP | ⚠️ 暂未启用（零构建 Vue 需 `unsafe-eval`，需真机浏览器复验） |
| 鉴权与暴力破解 | 四级角色；登录 5 次/分钟、注册 3 次/分钟（按 IP，兼容 X-Forwarded-For） |
| 上传安全 | 扩展名 + **文件魔数**双校验；路径穿越防护 |
| 密钥治理 | JWT 密钥未配置即拒绝启动；凭据文件已 gitignore |
| 隐私政策 | 首次启动强制同意 ✅ |

## 9 部署与运维

- **本机**：`启动后端.bat` 或 `java -jar ... --spring.profiles.active=local`
- **容器**：`docker compose -p examprep up -d --build`（MySQL + 后端 + Nginx；**必须注入 `JWT_SECRET`**）
- **HTTPS**：提供 `nginx-https.conf.example` 模板（证书/域名待填）
- **备份**：`backup.bat`
- **上架前自检**：`上架前检查.ps1`（只读，输出 FAIL/WARN 与退出码）
