# 详细设计说明书

> 项目：大学生多考试备考知识库与题库系统 · v1.0
> 本文覆盖系统的核心机制实现细节，配套源码注释阅读。

## 1 认证与权限设计

### 1.1 认证流程
1. `POST /auth/login`：学号 + 密码 → BCrypt 校验 → 生成 JWT（HS256，含 userId/role，有效期由配置决定）
2. 客户端携带 `Authorization: Bearer <token>`；`JwtAuthFilter` 解析并注入 SecurityContext
3. `POST /auth/guest`：游客入口，颁发仅含 GUEST 角色的短时 token

### 1.2 接口访问级别（三级）
- **PUBLIC**：匿名白名单（SecurityConfig `PUBLIC_ALL` / `PUBLIC_GET` 常量集中声明）——首页聚合、搜索、考试类别/科目/知识点树、题目列表与详情（只读）、资料列表与详情（只读）、前 3 页预览图、公告、管理端静态页
- **AUTH**：需登录（默认兜底 `anyRequest().authenticated()`）
- **ROLE:xxx**：方法级 `@PreAuthorize("hasAnyRole('AUDITOR','ADMIN')")` 等

### 1.3 防爆破限流
`RateLimitFilter`（@Order(1)）：同一 IP 对 `POST /auth/login` 60 秒窗口最多 5 次，超出返回 **429**。固定窗口计数（ConcurrentHashMap + Deque），仅保护登录入口。

### 1.4 登录过期
`ApiClient`（App 端 OkHttp 拦截器）检测 401 → 清除本地 token → 跳转登录页。

## 2 判分服务（JudgeService）

统一入口 `judge(Question, options, answer, userAnswer)`，按题型分派：

| 题型 | 判分逻辑 |
|---|---|
| SINGLE_CHOICE / TRUE_FALSE | 用户键 == isAnswer=1 的选项键 |
| MULTI_CHOICE | 用户多选集合与正确集合完全一致（忽略顺序） |
| FILL_BLANK | 用户答案按 `\|` 拆分，逐空比对（忽略首尾空格；caseSensitive=false 时忽略大小写）；数量必须一致 |
| MATCHING | answerContent.pairs 键值对 vs 用户答案 `A:1,B:3`（兼容 = 与全角冒号） |
| ORDERING | answerContent.order 序列 vs 用户答案 `C,A,B` 逐位比对 |
| 主观题 | 返回 null（不判对错）→ 前端展示 reference + 评分要点 → 自评接口（会/模糊/不会） |
| 组合题 | `judgeComposite`：查子题逐题递归判分，全部正确才算对；返回「子题 n/m 正确」 |

自评结果流转：错题本（自评「不会」入错题本）→ 知识点掌握度 → 刷题统计 → 正确率折算。

## 3 审核状态机（AuditService，题目与资料共用）

```
DRAFT ──提交──▶ PENDING ──通过──▶ APPROVED ──下架──▶ OFFLINE ──申诉──▶ APPEALING ──┬─通过──▶ APPROVED
                     │                          │                                  └─驳回──▶ OFFLINE
                     └─驳回──▶ REJECTED ──重新提交──▶ PENDING
```
- 每次流转写 `audit_record`（审核员、动作、原因、时间）+ 发通知
- **自我回避**：审核对象 uploader/creator == 当前审核员时抛 4001「不能审核自己上传的内容」
- Service 层 `@Transactional` 保证状态与审计记录原子性

## 4 预览与下载（防盗）

### 4.1 预览
1. PDF 资料首次预览时，PDFBox 逐页转 PNG 存 `resource_page`（页号 + 图片文件）
2. `GET /resources/{id}/preview`：游客返回前 3 页**低清**图地址；登录用户返回**整本高清**
3. 每页图叠加**因人而异水印**（学号/昵称，居中平铺半透明）——防传播溯源
4. App 端 Glide 分页加载图片，不使用系统阅读器在线预览

### 4.2 下载
1. `POST /resources/{id}/download`：校验登录 + APPROVED 状态 → 生成**短时效签名 URL**（fileId + 过期时间戳 + HMAC-SHA256）→ 写 `download_record`
2. `GET /files/download/{fileId}?...&sign=...`：白名单放行，业务层验签 + 过期校验

## 5 文件上传
- 类型白名单独立服务端校验（不信任前端）：图片 `jpg/jpeg/png/webp/gif`（App）；文档 `pdf/doc/docx/xls/xlsx/ppt/pptx/zip/txt` + 媒体 `mp4/mp3` 等（管理端）；违规返回 **415**
- 大小限制：图片 10MB、文档 200MB、音频 50MB；超限返回 **413**
- MD5 去重：同内容文件只存一份

## 6 模拟考试
1. `POST /exams/mock/start`：按科目随机抽取已开放客观题组卷，创建考试记录与 deadline
2. 作答：`POST /exams/mock/{id}/answer` 覆盖式保存（同题重复作答以最后一次为准）
3. 交卷：`POST /exams/mock/{id}/submit`（或倒计时归零前端自动交卷）→ 逐题判分 → 得分/得分率/明细
4. 计时：剩余秒数随试卷下发，前端 CountDownTimer 展示并兜底自动交卷

## 7 编程题在线运行（CodeRunService）

> ⚠️ **默认关闭**：`app.code-run.enabled` 默认 `false`，此时 `CodeRunController` 不注册（`@ConditionalOnProperty`），`POST /api/run` 返回 **404**。开启需显式 `--app.code-run.enabled=true` 或 `APP_CODE_RUN_ENABLED=true`，且**必须先在独立判题沙箱完成隔离验收**（容器/nsjail + `--network=none` + 只读 rootfs + 非 root + CPU/内存/PID 配额 + 编译与运行分离超时 + 输出硬上限 + 全局并发上限），结论见 `项目规划/第9周/03_代码运行沙箱_2026-11-08.md`。

- 临时目录写入源码 → 编译（C 用 gcc；Java 用服务自身 JDK 单文件运行）→ 注入 stdin → 捕获 stdout/stderr
- 超时 10 秒 `destroyForcibly`；临时目录 finally 清理
- 输出与 `expectedOutput` 去首尾空白比对返回 matched
- **边界声明**：本机受控子进程执行，无 CPU/内存/网络/文件系统隔离、环境变量全继承，仅适合本机单人调试；公网部署必须换独立判题沙箱

## 8 推荐排序与评分下沉（ResourceService）
- `?sort=recommended`：权重 =（下载量×2 + 有效评分×min(评分人数,5)）/（发布天数+7）
- **评分下沉**：评分人数 < 3 时不计入评分权重，防止少量刷分影响排序
- 时间衰减：新资料获得更高权重

## 9 搜索
- `GET /search`：聚合搜索（题目 + 资料）
- `GET /search/resources`：资料标题关键词分页搜索
- 资料标签：逗号分隔存储，`FIND_IN_SET` 精确筛选（重点必考/含答案/无答案/近年高频）

## 10 统计服务
- 仪表盘：用户数/题目数/资料数/待审数×2/待处理举报/下载量/今日新增
- 热门科目 TOP10（资料数 + 下载量）、活跃用户 TOP10（练习次数）、各题型正确率（答题明细聚合）

## 11 操作日志
`OperationLogService` AOP/手动埋点记录：登录、审核、修改、删除；字段含操作人、模块、动作、对象、详情、IP、UA。`GET /admin/logs`（ADMIN 全部）、`GET /admin/logs/audit`（AUDITOR 仅审核日志）。
