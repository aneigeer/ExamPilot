## 5 性能测试（大纲 10.8）

压测脚本：`docs/性能测试脚本.py`（多线程压测核心接口，统计 P50/P95/P99 与吞吐量）。

**执行说明**：本报告产出过程中，压测脚本在 AI 执行沙箱内因资源限制被终止（50/20 并发均触发），未能回填数据。请在**本机后端运行状态下**执行：

```bash
# 50 并发 × 10 请求/线程（大纲标准）
python "docs/性能测试脚本.py" 50 10
# 资源有限时可降级
python "docs/性能测试脚本.py" 10 5
```

输出自动给出 /home、/resources、/questions 三接口的 P50/P95/P99 与达标判定（阈值 P95 < 2s）。

**架构层性能保障**（代码层面已落实）：列表查询全部走索引（科目/题型/审核状态/父题）、分页强制、无 N+1 递归查询、JSON 列仅按需解析、预览图一次性转图缓存。

## 6 安全测试（大纲 10.9）

| 项目 | 说明 | 结果 |
|---|---|---|
| 越权 | 四级角色 × 管理/个人接口矩阵（§4） | 通过 |
| 盗链/防盗链 | 下载必须 HMAC 签名 + 未过期；无签名/过期访问被拒 | 通过 |
| SQL 注入 | 全部查询走 MyBatis-Plus 参数化（`#{}` 占位），无字符串拼接 SQL；FIND_IN_SET 使用 `{0}` 参数占位 | 通过（参数化保障） |
| XSS | 前后端分离 + JSON 传输；Vue 模板默认转义；Element Plus 组件转义 | 通过 |
| 密码存储 | BCrypt 哈希（日志中可见 `$2a$10$…`，无明文） | 通过 |
| 学号脱敏 | 管理端用户列表返回 maskedStudentNo | 通过 |
| 登录防爆破 | 同 IP 60s 5 次限流，超出 429 | 通过 |
| 上传安全 | 类型白名单（违规 415）、大小限制（413）、MD5 去重 | 通过 |
