# 需求规格说明书

> 项目：大学生多考试备考知识库与题库系统
> 版本：v1.0（对应大纲 v2，2026-09-23）
> 性质：软件工程课程设计 / 毕业设计，完整原型，不商用、不上架

## 1 引言

### 1.1 编写目的
明确系统的功能需求与非功能需求，作为设计、开发、测试与验收的依据。

### 1.2 背景
- 期末资料零散，四六级、计算机二级资料混杂，真假难辨
- 题库与资料分离，刷题、看笔记、下载资料来回切换
- 课程、教师、学年学期不匹配，劣质资料无人审核
- 现有题库多只支持选择题，大题、作文、翻译无法练习

### 1.3 目标
建立「考试类别 → 科目 → 知识点 → 题目/资料」的统一知识库，支持校内课程、CET4、CET6、计算机二级；实现刷题、判分、错题本、资料上传、审核、预览、下载完整闭环；实现游客、学生、审核员、超管四级权限。

### 1.4 用户角色

| 角色 | 能力 |
|------|------|
| 游客 | 浏览、搜索、公告、题库只读、资料前 3 页低清预览 |
| 学生 | 游客能力 + 刷题判分、主观题自评、错题本、收藏、笔记、上传（图片）、下载、评论、评分、举报、申诉、关注 |
| 审核员 | 学生能力 + 题目审核、资料审核、举报处理；**不可审核自己上传的内容** |
| 超管 | 全部权限，含用户管理、公告、统计、日志、基础数据维护 |

### 1.5 边界
- 资料以模拟题、原创题、授权资料、回忆题型为主；禁止官方真题与考试原题
- 不接真实教务系统，课程、教师、开课班使用模拟数据
- 文件初期本地磁盘，后期可换 MinIO；不追求真实高并发，使用稳定即可
- 学生端做 Android App（不做 iOS/小程序）；管理端做 Web
- 主观题采用「自评 + 参考答案」，不引入 AI 自动判分
- **App 端上传仅开放图片格式（jpg/jpeg/png/webp/gif）；PDF/DOCX/ZIP 等文档经管理端 Web 上传**

## 2 功能需求

### 2.1 分期范围

| 分期 | 内容 | 状态 |
|---|---|---|
| **P0-A** 使用闭环 | 认证权限、考试知识体系、P0 五题型刷题判分自评、错题本、资料上传审核预览下载、通知公告、后台管理 | 已完成 |
| **P0-B** 增强 | 导入导出、收藏题、笔记、收藏夹、下载历史、评论评分点赞、统计图表、资料标签、自评主观题开放、搜索排序 | 已完成 |
| **P1** 后置 | 模拟考试+组卷、申诉、关注、编程题在线运行、听力音频、复杂题型（匹配/排序/完形/阅读/组合）、媒体上传 | 已完成 |
| **P2** 展望 | 只写展望（推荐算法、AI 批改、教务对接、MinIO） | 按大纲不做 |

### 2.2 题型体系（23 种枚举全预留，分期开放）

- **客观题（自动判分）**：单选★、多选★、判断★、填空★、匹配、排序、完形填空、阅读理解、听力选择题、选词填空
- **主观题（自评）**：简答★、名词解释、计算、应用、作文、翻译、论述、编程、案例分析、改错、完形主观填空、证明
- **组合题（P1）**：材料题 / 阅读理解大题 / 听力大题（父子题结构）

★ = P0。当前已开放 17 种题型。

### 2.3 核心业务流程

1. **刷题闭环**：选模式（顺序/随机/按题型/按知识点/按难度/错题重做）→ 作答 → 客观题自动判分 / 主观题对照参考答案自评 → 报告 → 错题本 → 掌握度统计
2. **资料闭环**：上传（App 图片 / 管理端文档）→ DRAFT → PENDING → 审核员通过/驳回（驳回可重新提交）→ APPROVED → 游客低清 3 页预览 / 登录高清整本 → 签名 URL 下载 → 举报 → 核验成立下架 → 申诉 → 恢复或维持
3. **模拟考试**：随机组卷（客观题）→ 计时 → 覆盖作答 → 交卷自动判分 → 成绩报告

### 2.4 审核状态机（题目与资料共用）

```
DRAFT → PENDING → APPROVED / REJECTED → OFFLINE → APPEALING → APPROVED(恢复) / OFFLINE(维持)
                        ↓ 重新提交
                      PENDING
```
约束：审核员不可审核自己上传的内容（自我回避）。

## 3 非功能需求

### 3.1 多端兼容
- 学生端：Android 8+（API 26），compileSdk 34；触控目标 ≥ 44px；单列布局无横向滚动
- 管理端：Chrome / Edge / Safari，电脑优先，手机可简单使用
- 弱网、断网、加载中、空状态、错误提示完整

### 3.2 性能
核心接口 P95 < 2 秒；上传/下载/预览放宽到 5 秒；50 并发测试通过。

### 3.3 安全
JWT 鉴权、后端逐接口权限校验（PUBLIC / AUTH / ROLE:xxx 三级标注）、匿名白名单、文件类型白名单 + 大小限制 + MD5 去重、预览水印、下载签名 URL（短时效）、密码 BCrypt 哈希、学号脱敏、登录接口防爆破限流（429）。

### 3.4 可用性与可扩展性
统一响应结构（code/message/data/traceId）、统一异常处理、操作日志；后续可接教务系统、对象存储、推荐算法、AI 批改。

## 4 验收标准
1. Android App 可安装、可用：浏览、搜索、刷题、错题本、上传、预览、下载、通知
2. 管理端 Web 可用：审核、举报、用户、公告、统计、日志
3. 游客、学生、审核员、超管四级权限可用
4. P0 五种核心题型跑通：客观题自动判分、主观题自评闭环
5. 刷题闭环、资料闭环可跑通
6. 核心接口 P95 < 2 秒
7. App 触控目标不小于 44px，无横向滚动
8. 文档、源码、数据库脚本、测试报告齐全
