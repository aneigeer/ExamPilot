# 用户手册

> 项目：大学生多考试备考知识库与题库系统 · v1.7
> 适用对象：学生（App 用户）、审核员与超管（管理端用户）

## 1 系统要求

- **学生端**：Android 8.0 及以上手机；安装 `ExamPilot学生端-v1.9.1-真机版.apk`（直接拖入手机安装）
- **管理端**：Chrome / Edge / Safari 浏览器
- **后端**：本机已运行（端口 8080）
- **网络**：**手机与电脑必须连同一个 WiFi/热点**。APK 里内置的是打包时的电脑局域网 IP，
  换了网络就连不上（表现：登录提示网络错误）。此时需要重新打包或改用 HTTPS 域名方案
- **AI 功能（可选）**：需在本机启动 AI 服务（`ai-service/run.bat`）并保持 Ollama 在运行；
  未启动时问答会降级为纯检索、面试功能提示「服务暂不可用」，其余功能不受影响

## 3 学生端（Android App）

### 3.1 登录
打开 App → 输入学号密码 → 登录；或点「游客浏览」（只能浏览、看 3 页低清预览，不能刷题/上传/下载）。

### 3.2 底部导航（4 个 tab）
- **首页**：平台统计、公告、考试类别、热门资料；右下角 **＋ 悬浮按钮** = 上传资料；顶部搜索条
- **题库**：考试类别卡片（校内课程/CET4/CET6/计算机二级）→ 选科目 → 知识点树 → 点「按科目刷题」或点知识点刷该知识点 → 浏览题目
- **课程库**：「课程 / 资料」切换 —— 课程按学院+学期筛选；资料支持标题搜索与标签筛选（重点必考/含答案/无答案/近年高频），列表上拉加载更多
- **我的**：学习统计（练习次数/正确率/错题/收藏）与全部个人功能入口

### 3.3 刷题
首页「开始刷题」→ 配置（科目/题型/模式/范围/难度/题数）→ 开始：
- 客观题：点选项作答 → 立即判分（对/错 + 正确答案 + 解析）
- 填空：输入答案（多个空用 `|` 分隔）
- 主观题：输入回答 → 提交 → 对照参考答案 → 自评「会了 / 模糊 / 不会」（作答自动保存草稿）
- 匹配题：按 `A:1,B:3` 格式作答；排序题：按 `C,A,B` 顺序作答
- 组合大题：材料 + 子题逐题作答后整体提交
- 顶部「答题卡」查看进度；答完自动出报告（正确率 + 逐题明细）
- 做错的题自动进入「我的 → 错题本」；点顶部「复习」进入**间隔重复复习**：按遗忘曲线（1/2/4/7/15/30/60 天）只练到期的错题，先回忆→「对答案」→自评「答对了 / 答错了」，答对推进一轮、答错回到第一轮，走完全部轮次即视为掌握；列表中可长按移出

### 3.4 资料浏览与上传下载
- 资料列表 → 详情：**在线预览**（游客前 3 页低清带水印；登录整本高清）、**下载**（签名链接，浏览器下载后可用系统阅读器打开）、**收藏**、**评论/点赞**
- 上传：首页 FAB → 相册多选图片（自动压缩）→ 填标题/类型/科目/简介 → 提交审核；PDF/DOCX/ZIP 等文档请到电脑端管理后台上传
- 上传记录可在「我的 → 上传记录」查看审核状态

### 3.5 举报与申诉
- 资料详情页点「🚨 举报此资料」→ 填理由提交
- 自己被下架的资料：详情页点「⚖️ 对下架结果申诉」→ 「我的 → 我的申诉」查看处理结果

### 3.6 模拟考试
首页「模拟考试」→ 选科目/题数/时长 → 限时作答（顶部倒计时，可用答题卡题号跳转）→ 交卷（或时间到自动交卷）→ 成绩报告

### 3.7 其他
「我的 → 我的关注」管理关注科目/课程；「通知中心」查看审核/举报结果与公告（进入自动标记已读）；「账号设置」可修改密码，并可**导出个人数据**（含账号资料/统计/错题/练习记录/收藏/笔记的 JSON，可保存或分享）与**注销账号**（输入密码二次确认后，身份信息即刻匿名化、不可恢复）。

### 3.8 AI 导学问答

入口：首页「问 AI」横幅。**需登录**（未登录会先引导登录——匿名调用会直接占用本地大模型的生成资源，且问答要读学情画像做加权）。

1. 输入问题，例如「进程和线程的区别」「死锁的四个必要条件」
2. 回答下方会列出**来源卡片**（课件/题目/知识点 + 页码），点开可跳回原文
3. 答案里的 `[1][2]` 是**真实引用编号**，与来源卡片一一对应；系统会校验，假引用不会外流
4. 提问太宽泛时会反问你（「你是指课程知识还是题目讲解？」）；资料里没有的内容会直接说
   「未找到相关资料」，不会编造
5. 常见主题（操作系统章节级问题）会走「速答」，**0.05–0.3 秒**返回；细粒度问题走检索 + 本地大模型，
   约 **2–8 秒**

> 提示：① AI 服务未启动时问答会退化为本地全文检索（仍可用，答案偏原文摘录）；
> ② 本地 7B 生成一次约 **20–45 秒**，属正常，请等加载提示消失；客户端超时设为 90 秒。

### 3.9 AI 模拟面试

入口：首页「AI 模拟面试」横幅（游客会提示先登录）。

1. 选主题（可留空 = 随机，如填「RAG」「Transformer」「多智能体」）与题数（3/5/8）
2. 点「开始面试」→ AI 出一道题，并标出**出题出处**（哪份资料）
3. 输入你的回答 → 发送，几秒后返回评分卡：
   - **得分**（0–100）与判定（正确 / 部分正确 / 不正确）
   - **命中要点** / **遗漏要点** / **参考答案**
4. 答得太短或得分低于 60 时，AI 会就同一题**追问一次**；追问作答会与原答**合并重新评分**
5. 答满题数后出**复盘报告**：总分、等级、逐题得分、优势、待提升、改进建议
6. 报告页可「再面一场」
7. **历史复盘**：面试页右上角「历史」→ 列出「主题 · 分数 · 时间」，点开可看当时每题的问题、
   你的作答、得分与命中/遗漏要点（追问会单独一行，能看到「提示前 vs 提示后」）

> 评分说明：正常走本地 7B 判分；模型不可用时走抽取式对比，会明确标注
> 「非模型判分，需人工复核」。评分是练习参考，不等于真实面试结论。

## 4 管理端（Web）

打开 `http://localhost:8080/api/admin/index.html` → 审核员或超管账号登录。

| 菜单 | 功能 |
|---|---|
| 仪表盘 | 用户/题目/资料/待审核/举报/下载量统计 + 热门科目、活跃用户、题型正确率 TOP10 |
| 题目审核 | 按题型/关键词筛选 → 通过 / 驳回（填原因）/ 下架 |
| 资料审核 | 待审核 / 已审核切换 → 通过 / 驳回 / 下架 |
| 举报处理 | 成立并下架 / 不成立 |
| 申诉处理 | 通过恢复（资料重新公开）/ 驳回维持下架 |
| 用户管理 | 角色调整、禁用/启用 |
| 题目管理 | 新建题目（P0 五种题型表单，提交后进入待审核）、删除 |
| 文件上传 | **文档类资料（PDF/DOCX/ZIP 等）唯一上传入口**：拖拽上传 → 填表单 → 提交审核 |
| 公告管理 | 发布 / 编辑 / 删除 |
| 基础数据 | 考试类别、科目、知识点、学院、教师维护 |
| 操作日志 | 全部操作记录（超管）；审核日志（审核员） |

> 注意：审核员不能审核自己上传的内容（系统自动拦截）。

## 5 常见问题

| 问题 | 处理 |
|---|---|
| App 登录提示网络错误 | 确认后端已启动；手机与电脑连同一 WiFi；APK 内置的是打包时的电脑 IP，换网络需重新打包 |
| 下载没反应 | 签名链接 10 分钟有效，重新点下载获取新链接 |
| 上传提示 415 | App 仅支持图片；PDF/DOCX/ZIP 请到管理端上传 |
| 登录提示「请求过于频繁」 | 1 分钟内登录失败超过 5 次，稍后再试 |
| AI 回答说「未找到相关资料」 | 语料里确实没有，或问题太宽泛；换个说法或指定课程/章节再问 |
| AI 问答很慢 / 面试评分要等十几秒 | 本地 7B 在 CPU/GPU 上生成需要时间（问答 2–8s、评分 5–20s），属正常；首题冷启动更久 |
| 面试提示「服务暂不可用」 | 电脑上的 AI 服务（`ai-service/run.bat`）没启动或已退出，重启后重试 |
| 面试提示「会话已过期」 | 面试会话保留 30 分钟，超时需重新开始 |

## 6 声明

### 6.1 隐私政策
- 本系统仅收集学号、昵称、学院等学习必需信息；密码以 BCrypt 哈希存储，不可逆
- 管理端展示的学号一律脱敏（如 2021****01）；下载记录仅本人可见
- 本系统为课程设计原型，不接入第三方统计，不收集设备信息

### 6.2 版权声明
- 平台仅允许上传：原创笔记、原创题、授权资料、回忆版题型整理
- **严禁上传官方真题、考试原题及未经授权的盗版资料**；上传即视为承诺拥有合法权利
- 违规内容由审核员下架；权利人可举报，经核验成立即删除

### 6.3 学术诚信声明
- 本平台定位为备考辅助工具，题目均为练习用途
- 严禁利用平台传播考试作弊材料；由此产生的后果由上传者自负

## 7 已知限制（2026-11-10 新增）

> 本节如实记录当前版本**已知的缺陷与边界**，用于试点前告知使用者与验收方。
> 完整取证与判定见 `项目规划/第10周/04_发布前检查表_2026-11-10.md`。

### 7.1 影响使用的三条（务必先读）

| # | 限制 | 影响 | 当前规避方式 |
|---|---|---|---|
| 1 | **Android APK 不可直接用于本轮试点** | 安装包内 `BASE_URL` 写死为 `https://10.200.83.194/api/`，与本机当前局域网 IP（实测 `10.200.86.72`）不在同一网段；且 HTTPS 证书白名单只覆盖旧 IP → 装到手机上必然「网络错误」 | **改用学生端网页版**：手机浏览器打开 `http://<电脑当前IP>:8080/api/student/index.html`。功能面与 App 高度重合（第 3 章描述的入口在网页版均有对应） |
| 2 | **AI 答疑只覆盖已审核语料** | 凡 `audit_status != APPROVED` 的题目/资料，AI 检索不到；新导入的题目若未走审核 + 索引重建，问答会答「未找到相关资料」 | 新内容上架后，由管理员执行「重建 AI 索引」（见 `docs/数据更新手册.md` §2.2） |
| 3 | **AI 答案的边界是「有据可依」** | 语料里没有的内容，系统会明确说「未找到相关资料」，**不会编造**；这是设计而非故障。问题太宽泛时会先反问澄清 | 换个说法，或指定课程/章节再问（如「操作系统的进程和线程区别」） |

### 7.2 AI 答疑的具体边界（避免误判为 bug）

| 现象 | 是缺陷吗 | 说明 |
|---|---|---|
| 回答 0.4 秒就出来了 | 否 | 命中了 **Wiki 热层**（常见章节级问题走速答，0.05–0.4 s） |
| 回答要等 20–45 秒 | 否 | 走本地 7B 模型生成（CPU）的正常耗时；客户端超时 90 秒 |
| 答案风格变成「原文摘录」 | 否 | 模型不可用时自动降级为抽取式，答案偏原文摘录，**引用仍真实**；响应会标 `extractiveMode` |
| 提示「服务暂不可用」 | 是（可修） | AI 服务（`ai-service/run.bat`）没启动或已退出，重启后重试 |
| AI 模拟面试评分标「非模型判分，需人工复核」 | 否 | 抽取式兜底时的明确提示，评分仅供参考，不等于真实面试结论 |
| 同一问题两次答得不完全一样 | 否 | 生成式模型的正常波动；引用来源应一致 |
| AI 反问「你是指课程知识还是题目讲解？」 | 否 | 问题过宽时的澄清设计 |

### 7.3 平台能力边界

| 项 | 现状 |
|---|---|
| 资料上传格式 | **手机端/学生端网页仅支持图片**（jpg/jpeg/png/webp/gif，单张 ≤ 10 MB）；PDF/DOCX/ZIP 等文档**必须在管理端上传**（≤ 200 MB） |
| 文档下载链接 | **10 分钟有效**，过期需重新点下载获取新链接 |
| 游客权限 | 只能浏览 + 看 **3 页**低清带水印预览；不能刷题/上传/下载 |
| AI 模拟面试会话 | 保留 **30 分钟**，超时需重新开始 |
| 登录态有效期 | **7 天**；管理员轮换服务端密钥后所有登录态立即失效（需重新登录） |
| 登录频率 | 同一来源 **60 秒内失败 5 次**触发限流（提示「请求过于频繁」），60 秒后自动恢复；注册为 3 次/60 秒 |
| 编程题在线运行 | **已默认关闭**（`POST /api/run` 不存在）。当前版本不提供「在线跑代码」功能，编程题按普通主观题作答、自评 |
| AI 智能体（Agent）多步问答 | **已默认关闭**（返回 503）。现有的 `/ai/ask` 单轮问答不受影响 |

### 7.4 已知缺陷（不阻断使用，但会被验收方问）

| # | 缺陷 | 用户可感知的表现 |
|---|---|---|
| 1 | 登录限流可被伪造请求头绕过 | 用户无感；属安全加固项，运维侧盯日志 |
| 2 | 无自动告警 | 服务异常时不会主动通知，需人工巡检 |
| 3 | 备份只保留历史 1 份、无加密 | 用户无感；运维侧需按周手动确认备份 |
| 4 | 运行日志可能含学号/姓名（未脱敏） | 用户无感；但**日志文件严禁外发**（隐私红线） |
| 5 | 账号注销后，AI 问答历史轨迹是否同步匿名化未验证 | 注销前建议自行导出个人数据留存（「我的 → 账号设置 → 导出个人数据」） |
| 6 | 管理端未做 Chrome/Edge/Safari 三浏览器交叉验证 | 建议用 Chrome 或 Edge 访问 |
| 7 | 无 SLO 定义 | 性能「变慢」无客观判定标准，仅靠人工体感 |

### 7.5 试点期间的人工兜底约定

1. **手机端统一用学生端网页版**，不发 APK（见 7.1 第 1 条）。
2. AI 答疑问题若全部返回「未找到相关资料」，**先确认 AI 服务是否在运行**，再判断是不是语料没覆盖。
3. 演示前手动备份一次数据库（避免演示中误操作不可恢复）。
4. 任何 5xx / 登录异常，**立即截图并记录页面上的 traceId**，这是唯一能定位到日志的凭据。
5. 试点管理员口令与数据库口令**只由一人掌握**，不通过聊天工具传递。
