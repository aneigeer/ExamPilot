# 用户手册

> 项目：大学生多考试备考知识库与题库系统 · v1.0
> 适用对象：学生（App 用户）、审核员与超管（管理端用户）

## 1 系统要求

- **学生端**：Android 8.0 及以上手机或模拟器；安装 `备考知识库学生端-v1.4-真机版.apk`（直接拖入手机安装）
- **管理端**：Chrome / Edge / Safari 浏览器
- **后端**：本机已运行（端口 8080）

## 3 学生端（Android App）

### 3.1 登录
打开 App → 输入学号密码 → 登录；或点「游客浏览」（只能浏览、看 3 页低清预览，不能刷题/上传/下载）。

### 3.2 底部导航（4 个 tab）
- **首页**：平台统计、公告、考试类别、热门资料；右下角 **＋ 悬浮按钮** = 上传资料；顶部搜索条
- **题库**：考试类别卡片（校内课程/CET4/CET6/计算机二级）→ 选科目 → 知识点树 → 点「按科目刷题」或点知识点刷该知识点 → 浏览题目
- **课程库**：「课程 / 资料」切换 —— 课程按学院+学期筛选；资料支持标题搜索与标签筛选（重点必考/含答案/无答案/近年高频），列表上拉加载更多
- **我的**：学习统计（练习次数/正确率/错题/收藏）与全部个人功能入口

### 3.3 刷题
首页「开始刷题」→ 配置（科目/题型/模式/范围/难度/题数）→ 开始：
- 客观题：点选项作答 → 立即判分（对/错 + 正确答案 + 解析）
- 填空：输入答案（多个空用 `|` 分隔）
- 主观题：输入回答 → 提交 → 对照参考答案 → 自评「会了 / 模糊 / 不会」（作答自动保存草稿）
- 匹配题：按 `A:1,B:3` 格式作答；排序题：按 `C,A,B` 顺序作答
- 组合大题：材料 + 子题逐题作答后整体提交
- 顶部「答题卡」查看进度；答完自动出报告（正确率 + 逐题明细）
- 做错的题自动进入「我的 → 错题本」；点顶部「复习」进入**间隔重复复习**：按遗忘曲线（1/2/4/7/15/30/60 天）只练到期的错题，先回忆→「对答案」→自评「答对了 / 答错了」，答对推进一轮、答错回到第一轮，走完全部轮次即视为掌握；列表中可长按移出

### 3.4 资料浏览与上传下载
- 资料列表 → 详情：**在线预览**（游客前 3 页低清带水印；登录整本高清）、**下载**（签名链接，浏览器下载后可用系统阅读器打开）、**收藏**、**评论/点赞**
- 上传：首页 FAB → 相册多选图片（自动压缩）→ 填标题/类型/科目/简介 → 提交审核；PDF/DOCX/ZIP 等文档请到电脑端管理后台上传
- 上传记录可在「我的 → 上传记录」查看审核状态

### 3.5 举报与申诉
- 资料详情页点「🚨 举报此资料」→ 填理由提交
- 自己被下架的资料：详情页点「⚖️ 对下架结果申诉」→ 「我的 → 我的申诉」查看处理结果

### 3.6 模拟考试
首页「模拟考试」→ 选科目/题数/时长 → 限时作答（顶部倒计时，可用答题卡题号跳转）→ 交卷（或时间到自动交卷）→ 成绩报告

### 3.7 其他
「我的 → 我的关注」管理关注科目/课程；「通知中心」查看审核/举报结果与公告（进入自动标记已读）；「账号设置」可修改密码，并可**导出个人数据**（含账号资料/统计/错题/练习记录/收藏/笔记的 JSON，可保存或分享）与**注销账号**（输入密码二次确认后，身份信息即刻匿名化、不可恢复）。

## 4 管理端（Web）

打开 `http://localhost:8080/api/admin/index.html` → 审核员或超管账号登录。

| 菜单 | 功能 |
|---|---|
| 仪表盘 | 用户/题目/资料/待审核/举报/下载量统计 + 热门科目、活跃用户、题型正确率 TOP10 |
| 题目审核 | 按题型/关键词筛选 → 通过 / 驳回（填原因）/ 下架 |
| 资料审核 | 待审核 / 已审核切换 → 通过 / 驳回 / 下架 |
| 举报处理 | 成立并下架 / 不成立 |
| 申诉处理 | 通过恢复（资料重新公开）/ 驳回维持下架 |
| 用户管理 | 角色调整、禁用/启用 |
| 题目管理 | 新建题目（P0 五种题型表单，提交后进入待审核）、删除 |
| 文件上传 | **文档类资料（PDF/DOCX/ZIP 等）唯一上传入口**：拖拽上传 → 填表单 → 提交审核 |
| 公告管理 | 发布 / 编辑 / 删除 |
| 基础数据 | 考试类别、科目、知识点、学院、教师维护 |
| 操作日志 | 全部操作记录（超管）；审核日志（审核员） |

> 注意：审核员不能审核自己上传的内容（系统自动拦截）。

## 5 常见问题

| 问题 | 处理 |
|---|---|
| App 登录提示网络错误 | 确认后端已启动；模拟器用默认地址，真机需把 BASE_URL 改为电脑局域网 IP 后重新打包 |
| 下载没反应 | 签名链接 10 分钟有效，重新点下载获取新链接 |
| 上传提示 415 | App 仅支持图片；PDF/DOCX/ZIP 请到管理端上传 |
| 登录提示「请求过于频繁」 | 1 分钟内登录失败超过 5 次，稍后再试 |

## 6 声明

### 6.1 隐私政策
- 本系统仅收集学号、昵称、学院等学习必需信息；密码以 BCrypt 哈希存储，不可逆
- 管理端展示的学号一律脱敏（如 2021****01）；下载记录仅本人可见
- 本系统为课程设计原型，不接入第三方统计，不收集设备信息

### 6.2 版权声明
- 平台仅允许上传：原创笔记、原创题、授权资料、回忆版题型整理
- **严禁上传官方真题、考试原题及未经授权的盗版资料**；上传即视为承诺拥有合法权利
- 违规内容由审核员下架；权利人可举报，经核验成立即删除

### 6.3 学术诚信声明
- 本平台定位为备考辅助工具，题目均为练习用途
- 严禁利用平台传播考试作弊材料；由此产生的后果由上传者自负
