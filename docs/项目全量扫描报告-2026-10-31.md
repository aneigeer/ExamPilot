## 5. 配置生效矩阵（开发最容易踩的坑）

| 能力 | 默认（无 profile） | `local` | `prod` |
|---|---|---|---|
| 大模型 | Ollama 7B | 同 | 同 |
| 向量通道 / FastAPI | **关** | **开** | 关 |
| 语义闸门 | 不生效 | 生效 | 不生效 |
| **Agent** | **关** | **关** | **关** |
| 异步队列 / Wiki 蒸馏 | 关 | 关 | 关 |
| 对象存储 MinIO | 关（纯本地） | 关 | 关 |

三条必须记住的结论：

1. **Agent 三处都默认关**，要用必须显式加 `--app.ai.agent.enabled=true`（且 Python 侧 `AGENT_ENABLED=true`、Redis 起来）。
2. `app.ai.llm.provider=ollama` **压不住 Ollama**：`OllamaLlmClient.available()` 不看 provider 且 `@Order(5)` 最小，本地模型可达就永远优先。
3. `app.ai.route.enabled` 是**死开关**：`AiRouteClient` 已是 `@Component`，但主代码无调用点，改 true 不产生任何行为。

其他关键键：`app.ai.internal-token`（空 → `/internal/**` 全 403，fail-closed）、`min-term-coverage=0.5`、`min-vector-score=0.55`、`semantic-reject-score=0.62`、`wiki.hit-threshold=0.55`、`agent.max-steps=6 / max-tool-calls=4`、限流硬编码在 `RateLimitFilter`（登录 5 次/分、注册 3 次/分）。
