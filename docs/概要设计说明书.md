# 概要设计说明书

> 项目：大学生多考试备考知识库与题库系统 · v1.0

## 1 总体架构

```
┌─────────────────┐   ┌──────────────────┐
│  Android 学生端   │   │   Web 管理端      │
│  Java+XML+MVVM   │   │  Vue3+ElementPlus │
│  Retrofit/Glide  │   │  （托管于后端同源）  │
└────────┬────────┘   └────────┬─────────┘
         │      REST / JSON / JWT
         ▼                     ▼
┌─────────────────────────────────────┐
│      Spring Boot 3.5.3 后端          │
│  Controller → Service → Mapper(MP)  │
│  Spring Security 6 + JWT (jjwt)     │
│  PDFBox 预览转图 · 水印 · 签名 URL    │
│  判分服务 · 审核状态机 · 统计服务      │
└──────┬──────────────┬───────────────┘
       ▼              ▼
┌────────────┐  ┌──────────────┐
│  MySQL 8   │  │ 本地磁盘文件   │
│  40 张表    │  │ uploads/ 目录 │
└────────────┘  └──────────────┘
```

- 后端统一 REST API（132 个接口），context-path 为 `/api`
- 管理端静态资源由后端同源托管（`/api/admin/index.html`），零跨域、零部署
- 统一响应：`{ code, message, data, traceId }`；分页：`{ page, size, total, list }`

## 2 技术选型（与本机实测环境对齐）

| 端 | 技术 |
|---|---|
| 后端 | JDK 21（Temurin 21.0.10）、Spring Boot 3.5.3、Spring Security 6、JWT（jjwt 0.12.6）、MyBatis-Plus 3.5.7（spring-boot3-starter）、springdoc-openapi 2.8.6、PDFBox 3.0.7、Lombok、MySQL 8（8.0.46） |
| 学生端 | Android 原生 Java + XML 布局 + ViewBinding + MVVM 思想（数据层独立封装）、Retrofit 2.11 + OkHttp 4 + Gson、Glide、RecyclerView、BottomNavigationView、FloatingActionButton、SwipeRefreshLayout（compileSdk 34 / minSdk 26，Gradle 8.7 + AGP 8.5.2） |
| 管理端 | Vue3 + Element Plus（CDN 本地化，单页应用，由后端同源托管） |

硬性规范：全部使用 `jakarta.*`（禁 javax.*）；使用 SecurityFilterChain（禁 WebSecurityConfigurerAdapter）；App 禁用 Jetpack Compose（Java 项目）；列表用 RecyclerView；ViewBinding 替代 findViewById。

## 4 关键设计决策

| 决策 | 方案 | 理由（见大纲 13.4 防翻车清单） |
|---|---|---|
| 全题型答案存储 | 题目答案表 MySQL JSON 字段，按题型存不同结构；客观题答案存选项表 is_answer | 23 种题型答案结构差异大，禁止大宽表 |
| 判分 | 统一 JudgeService，按题型分派；组合题逐子题判分 | 避免判分逻辑分散 |
| 防盗预览 | 后端 PDFBox 将 PDF 转图片：游客前 3 页低清 + 水印，登录整本高清 + 水印；下载走短时效 HMAC 签名 URL | 系统阅读器会打开整本，无法控页 |
| 下载防盗链 | 签名 URL = fileId + 过期时间戳 + HMAC-SHA256 | 防盗链、短时效 |
| 匿名白名单 | SecurityConfig 先声明白名单，再声明需登录规则 | 游客联调全线 401 的教训 |
| 上传格式 | App 仅图片（服务端独立白名单校验，非图片 415）；文档走管理端 | 控制审核成本与存储 |
| 组合题 | parent_id 关联子题，详情按父子结构返回 | 先设计好关联与排序 |
| 审核状态机 | 统一状态机含申诉出口；Service 层事务；自我回避 | 补齐 APPEALING 出口 |

## 5 部署架构（使用）

本机：`mvn spring-boot:run` 启动后端（内嵌管理端页面）→ 浏览器 `http://localhost:8080/api/admin/index.html`；APK 直接安装，模拟器通过 10.0.2.2 访问宿主机。
正式：Docker Compose（eclipse-temurin:21-jre）+ Nginx（见部署文档）。
