**Request**

**Response**
| 字段 | 类型 | 取值域 / 约束 | 说明 |
|---|---|---|---|
| `skill` | `str` | 11 值枚举：`COURSE_QA` / `COURSEWARE_QA` / `EXERCISE_EXPLAIN` / `RESOURCE_RECOMMEND` / `STUDY_PLAN` / `WRONG_BOOK_REVIEW` / `GRADING` / `SMALLTALK` / `INTERVIEW` / `REFUSE` / `CLARIFY` | 与 `SkillName`（`router/schemas.py:15`）**逐字一致，不得改名** |

| `sim` | `float` | `[0,1]`，4 位小数 | Top1 余弦 |
| `margin` | `float` | `[0,1]`，4 位小数 | Top1−Top2 |
| `reason` | `str` | `ROUTED` / `SIM_LOW` / `MARGIN_LOW` / `FALLBACK` | 与 `RouterDecision.reason` 一致 |

| skill | source_types |
|---|---|
| `COURSE_QA` | `QUESTION, KNOWLEDGE`（`registry.py:21`；注意运行时另有 `retrieval_groups` 追加 COURSEWARE 一组，**route 只回声明值**） |
| `COURSEWARE_QA` | `COURSEWARE` |
| `EXERCISE_EXPLAIN` | `QUESTION` |
| `RESOURCE_RECOMMEND` | `RESOURCE, COURSEWARE` |
| `STUDY_PLAN` | `COURSEWARE, KNOWLEDGE` |
| `WRONG_BOOK_REVIEW` | `QUESTION, KNOWLEDGE` |
| `GRADING` | `QUESTION` |
| `INTERVIEW` | `COURSEWARE` |
| `SMALLTALK` / `REFUSE` / `CLARIFY` | `[]`（空） |

**错误码**（复用 `app/errors.py` 的 52xx 段，不新增）
| 码 | 场景 |
|---|---|
| `5200` | `question` 空白 / 超 200 字 |
| `5201` | Router 不可用（模型未加载等） |
| `5202` | 超时 |
| `5299` | 其他内部错误 |

> **`5201` 时不要返回 5xx 给 Java**：建议 Python 侧**自身**降级为 `COURSE_QA + [QUESTION,KNOWLEDGE]` 并 `reason=FALLBACK` 返回 200；

#### A3.2 SQL 改法（最小 diff，二选一）

**方案 1（推荐，最小 diff，不改 `@Select` 结构）**：CSV + `FIND_IN_SET`

```sql
-- 在 :45 的 WHERE 之后、:47 之前插入
AND (#{sourceTypesCsv} IS NULL OR FIND_IN_SET(c.source_type, #{sourceTypesCsv}) > 0)
```

**方案 2（可用索引，但需给 `searchByFulltext` 加 `<script>` 包裹）**：`foreach IN`

```xml
<if test="sourceTypes != null and sourceTypes.size() > 0">
  AND c.source_type IN
  <foreach collection="sourceTypes" item="st" open="(" separator="," close=")">#{st}</foreach>
</if>
```

| | 方案 1 | 方案 2 |
|---|---|---|
| diff 大小 | **1 行** | 需给 `:36` 的 `@Select("""` 加 `<script>`，并改签名 |
| 索引利用 | 不能走 `source_type` 索引 | 可走 |
| 实际性能 | 可忽略（`MATCH` 已是主要驱动，表 1.2 万行，取值仅 4 个） | 略优 |
| 风险 | 无 | 改 `@Select` 结构，**可能影响现有 16 个单测** |

> **推荐方案 1**：语料 1.2 万行、`source_type` 仅 4 个值，`FIND_IN_SET` 的代价远小于"改坏现有 SQL 结构"的风险。

#### B1.2 依赖实现要点（设计，非代码）

```
require_internal_token(x_internal_token: str = Header(None, alias="X-Internal-Token")):
    期望值 = settings.agent.internal_token        # config.py:214
    若 期望值 为空 → 403（fail-closed，与 Java InternalTokenFilter 一致）
    若 未提供或不等 → 401/403
    否则 放行
```

**三个必须遵守的细节：**
1. **`fail-closed`**：`internal_token` 未配置时**拒绝**，不是放行。与 Java `SecurityConfig:145` 注释"令牌未配置时一律返回 403"保持一致。
2. **挂 router 级**而非逐个函数：这样 `/v1/agent/stream` 与 `/v1/agent/run` **一次覆盖**（也顺带修 V5）。
3. **不改 `/v1/ask`**：它是评测/调试入口，且**不接受 userId**（无数据泄露面）。若要一并加，需先确认 `eval/` 脚本能带令牌。
